# Medication Routines

## Consistent timing

Medications, especially those for chronic conditions, should be given at the same time
each day. Consistency improves effectiveness and makes missed doses easier to spot.

## Missed doses

If a dose is missed, check the medication's instructions or consult a veterinarian before
doubling the next dose — some medications should never be double-dosed.

## Pairing with food

Some medications are better tolerated with food to reduce stomach upset; scheduling
medication tasks near feeding tasks can improve compliance.
